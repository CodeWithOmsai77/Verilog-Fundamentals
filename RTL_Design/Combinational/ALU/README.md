# 4-bit ALU

A 4-bit combinational Arithmetic Logic Unit implemented in **Verilog HDL**.

## Operations

| Select (S) | Operation | Result |
|---|---|---|
| 000 | Addition | A + B |
| 001 | Subtraction | A - B (two's complement) |
| 010 | AND | A & B |
| 011 | OR | A | B |
| 100 | XOR | A ^ B |
| 101 | NOT A | ~A |
| 110 | Shift left | A << 1 |
| 111 | Shift right | A >> 1 |

## Files

- `ALU.v` — synthesizable ALU RTL.
- `tb_ALU.v` — testbench that applies all eight select codes and displays the result and carry output.
- `dump.vcd` — waveform dump generated by the testbench.

## Simulation

Run from this directory:

```bash
iverilog -g2005 -o alu_sim ALU.v tb_ALU.v
vvp alu_sim
gtkwave dump.vcd
```

The testbench uses A = `0101` and B = `0011`, and iterates through all eight operations.
